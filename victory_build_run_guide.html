⚠ GPU DRIVER RESET (TDR), QTE CRASHES & UNVERIFIED FORK RISK

Early-Build Stability: Even when the game boots and runs in-world (~4 FPS on DexNom), expect crashes at early milestones (such as the first QTE) and occasional Windows TDR display driver resets. Only bare-minimum world assets load right now—nowhere near retail.

Inspect Before Building: Community forks move rapidly and contain experimental, unreviewed code. Always review the source code before compiling and never run precompiled .exe binaries from untrusted links. There is no official installer.

RAM & VRAM: A run in the world takes about 33 GB of Windows commit (RAM plus paging file) and ~8–10 GB VRAM (fits within 12 GB VRAM, though 32 GB system RAM relies on page file headroom). If crashes.log reports Windows error 1455, close other apps or increase the Windows paging file size.

First-Launch Pipeline Build (~2,500 Pipelines)
The first launch after a build translates every shader and builds roughly 2,500 pipelines; the loading screen can remain frozen—with sound playing—for minutes.
Memory Footprint (~33 GB Commit)
Commits roughly 33 GB after ~15 minutes of driving (title's ~7 GB, ~8 GB textures on GPU, buffer copies, and system backing of video memory).
Ray-Traced Light Stand-In Constant
No ray-traced light; a single constant stands in everywhere/every hour. Default 0.6 flattens night shadows and leaves noon unlit areas nearly black; levels that looked right on the author's machine: 0.07 bluish at night, 0.3 warm at dusk/dawn, 1.4 sky blue at noon.
Dropped Draws & Unimplemented Compute
Per-draw descriptor slots can run out in heavy areas, and ~380 draws per frame are dropped in the world due to untranslated programs and 6 pipelines refused by the AMD driver (2 compute, 4 mesh).
  • In-Game Phone Unlit: With the in-game phone out, the world is unlit (see the fork's table/notes).
  • Compute Passes & VICTORY_RAYS=1: Some compute programs (ray-tracing structure builders, wind volumes, and others) do not translate and their passes are dropped. Setting VICTORY_RAYS=1 translates/runs the builders, then removes the device ~1.5 minutes later (do not expect light from it; even after fixing stale list/descriptor names in Radeon GPU Detective, it ends on a read at an unmapped address).
  • Windows 10 vs. Windows 11: Reported not to get past startup on Windows 10 without a newer D3D12 runtime (issue #9, PR #44, unmerged/untested there); only run on Windows 11 in that setup.
  • Known Failing Tests & Repo Notes: list::tests::lists_are_cut_at_waits_that_follow_work in victory-gpu and five xmem tests in victory-hle fail (issues #2 and #8); crates/victory-shader/src/emit/lower.rs exceeds the cargo xtask size limit as source code (not an asset); many changes are title/GPU-specific and marked as shortcuts approximating console behavior.
Standalone Runtime · Leonida Architecture, Layout & Conventions
◈ LEONIDA RUNTIME REFERENCE (STANDALONE · GPL-3.0-or-later)
Leonida runs an Xbox Series executable from your own game installation on 64-bit Windows. The title's x86-64 code runs natively, console system APIs are provided by Leonida, and GPU work is translated to Direct3D 12. Game files, saves, and shader caches stay on your computer.
Requirements
  • OS & GPU: 64-bit Windows with a current Direct3D 12 driver (mesh shaders, Shader Model 6.6).
  • Toolchain: Rust 1.98 or newer.
  • MSVC / SDK: Visual Studio Build Tools with Desktop development with C++ (x64 MSVC toolset and a Windows 10 or 11 SDK).
Automated Install (Setup.cmd)
Double-click Setup.cmd, then select the Series X game executable inside your own extracted installation (or run .\Setup.cmd --game-path "D:\Games\SeriesX\game.exe"). Setup:
  • 1. Fetches and verifies the BCPack format tables,
  • 2. Builds Leonida.exe, LeonidaPlay.exe, and LeonidaWarm.exe,
  • 3. Installs them into %LOCALAPPDATA%\Leonida,
  • 4. Adds Leonida and Leonida (Experimental RT) to the Start menu.
Saves go to State, shader caches to Cache, and per-run diagnostics to Logs inside the install directory. Run Setup.cmd again to update. LeonidaWarm.exe warms the shader cache ahead of play.
