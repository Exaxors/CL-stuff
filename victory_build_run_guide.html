⚠ GPU DRIVER RESET (TDR) & UNVERIFIED FORK RISK

Expect Driver Resets Past the Menu: Entering the 3D open world on experimental builds frequently triggers Windows Timeout Detection and Recovery (TDR), temporarily blacking out your monitors and resetting the NVIDIA display driver. The latest runs did not crash, but it is not ruled out.

Inspect Before Building: Community forks move rapidly and contain experimental, unreviewed code. Always review the source code before compiling and never run precompiled .exe binaries from untrusted links. There is no official installer.

RAM & VRAM: A run in the world takes about 33 GB of Windows commit (RAM plus paging file) and about 10 GB of video memory. Check Committed under Task Manager → Performance → Memory. If crashes.log reports Windows error 1455, close other applications or increase the Windows paging file size, then retry.

System & Environment Requirements
Baseline Setup & Tooling
What your machine and workspace need before compiling or running the runtime.
Reference Only
Windows 10 / 11 (64-bit) + AVX2 CPU
Requires a modern 64-bit Windows environment on an AVX2-capable processor.
D3D12 SM 6.6 + Mesh Shaders RTX 5090 Ready
Needs a Direct3D 12 GPU with Shader Model 6.6 and Mesh Shader support; your RTX 5090 clears this easily.
Rustup & VS C++ Build Tools
Keep MSVC build tools and Rust installed. DexNom's setup script will use them to compile locally.
External Unpacked Xbox Series Build
Store your unpacked game build in a separate folder outside the DexNom runtime folder.
Build & Run Walkthrough
01
Download & Extract the Repository
Select the DexNom ZIP method. (The other forks use Git clone).

Selected: DexNom/VIctory — Community fork under active experimentation (use ZIP download).

POWERSHELL / BROWSER 
# DexNom: Download the ZIP from GitHub (Code -> Download ZIP)
# Extract it to a folder, e.g., D:\DexNom
git clone https://github.com/DexNom/VIctory.git # (Ignore for DexNom)
CHECKPOINT: The ZIP is extracted and you can see Setup.cmd inside the folder.
02
Run Setup.cmd (Auto-Compile)
DexNom handles the hooks, configuration, and compilation automatically.
WINDOWS EXPLORER 
# Double-click Setup.cmd in the extracted folder.
# When prompted, select your game executable on the F: drive.
.\Setup.cmd -GamePath "F:\gta\GTA VI\GTA6.Xbox.v1.0.2.1-CYBERLEEK\game_scarlett_master.exe"
CHECKPOINT: The setup script finishes and installs Start Menu shortcuts for "DexNom Runtime".
03
Launch from Start Menu
No manual shader translation required—the launcher handles it.
WINDOWS START MENU 
# Open Start Menu and search for "DexNom Runtime"
# Click the shortcut to play.
CHECKPOINT: The game boots, the menu appears, and first-time setup starts. (First world load will take ~1 minute and may run at 1 FPS).
04
Optional: Manual Launch (Advanced)
If you need to pass custom flags or run from the terminal.
Optional Launch Flags

Explanation: These flags are appended to the runtime executable. The DexNom launcher sets the paths automatically, so you only need these if you are using PowerShell.

POWERSHELL 
& "$env:LOCALAPPDATA\DexNom Runtime\victory-play.exe"
CHECKPOINT: The game launches directly from the terminal using your saved AppData configuration.
