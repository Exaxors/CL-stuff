Simple Steps
1
Install & Open Mandyhub
Get Mandyhub so it sets up the build tools and projects for you.

Download and run Mandyhub from github.com/Z-rox/mandyhub, and select your unpacked game folder at the bottom so Play can be used.

Check: Mandyhub opens cleanly and shows Status: Ready with your game folder path shown at the bottom.
2
Add Custom Repos in Mandyhub
Copy github.com/xxx/xxx below, paste it into Custom repo link (any git site) in Mandyhub, and click + Add.
VIctory-NVIDIA-RT (Current NVIDIA Lead)
github.com/Kemerd/VIctory-NVIDIA-RT
Paste github.com/Kemerd/VIctory-NVIDIA-RT into Mandyhub's custom repo box and click + Add.
cool_fox (NVIDIA — Ran "Fine" in Tests)
github.com/DoubleGhosty/cool_fox
Paste github.com/DoubleGhosty/cool_fox into Mandyhub's custom repo box and click + Add. NVIDIA also ran "fine" in my tests.
Check: Both repos appear in Mandyhub's project list, and you can click Install on the one you want to build.
3
Warm Shaders First (PowerShell)
Open a PowerShell window inside your built folder (%LOCALAPPDATA%\Mandyhub\target\<RepoFolder>\diag) and run this command:
POWERSHELL WINDOW · SHADER WARMING COMMAND 
.\victory.exe shaders "C:\Path\To\Your\Game\shaders.rpf"

Tip: If your PowerShell window is one folder up in ...\<RepoFolder>, use .\target\diag\victory.exe shaders "C:\Path\To\Your\Game\shaders.rpf". Replace C:\Path\To\Your\Game\shaders.rpf with your actual game's shaders.rpf path.

Check: PowerShell runs the shader command without a path/file error and starts building/caching shaders.
4
Play via Mandyhub
Once installed and shaders are warmed, select the project in Mandyhub and click Play.

If you ever add a custom link that duplicates a project already in the list and causes a duplicate card/widget warning, close Mandyhub and set custom:[] under "app" in %LOCALAPPDATA%\Mandyhub\app.ron.

Check: The game window opens from Mandyhub; on my R9 5900X + RTX 3060 12GB setup it hit 7fps max ("stable 3fps") without crashing.
